# Weather Node

A desk-side weather app that fetches a forecast, shows the current condition,
and warns when rain or bad air quality matters.

The first version can use any weather API. The SDK should eventually wrap
credentials and location permissions so app authors only define the experience.

## Useful Extensions

- Hourly rain warning.
- Air quality warning for parents and kids.
- Commute prompt before leaving home.
- Voice summary when tapped.
