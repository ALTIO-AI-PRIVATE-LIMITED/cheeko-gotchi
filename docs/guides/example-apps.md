# Example Apps

Cheeko examples should be small enough to read in one sitting and useful enough
to become a real app after one weekend of iteration.

## Start Here

1. `examples/animated_face`
   Learn display primitives, animation timing, blinking eyes, and talking mouth
   states. This should become the default personality layer for many apps.

2. `examples/weather_node`
   Learn Wi-Fi, cloud data fetches, and glanceable dashboard screens.

3. `examples/pill_guard`
   Learn reminder flows, confirmations, tones, and family escalation hooks.

4. `examples/market_pulse`
   Learn periodic refresh, API-backed widgets, and one-tap cloud explanations.

5. `examples/focus_beacon`
   Learn timers, ambient device states, and friendly interruption design.

6. `examples/cloud_voice_bot`
   Learn push-to-talk cloud voice sessions using the microphone path.

7. `examples/fridge_magnet`
   Learn storage-backed lists, touch hit-testing, and glanceable home widgets.

8. `examples/claude_agent`
   Learn the cloud text round-trip, word-wrapped reply layout, and button
   scrolling.

9. `examples/tilt_maze`
   Learn accelerometer tilt physics and partial redraws that stay fast on real
   hardware.

10. `examples/cheeko_pet`
    Learn the full pet pattern: persistent stats, uptime-driven decay, and
    mood-driven faces.

## Recommended Pattern

Keep each app focused:

- One home screen.
- One main interaction.
- One cloud permission.
- One useful reason to stay on the desk or bedside table.

If an idea needs many screens, split it into modes first. A tiny device feels
best when it is calm, glanceable, and predictable.
